# Быстрый старт

## Сборка сайта

```bash
git clone https://github.com/celestia-island/lagrange
cd lagrange
cargo run --release -- build docs --out target/site
```

Откройте `target/site/index.html` — он перенаправит на английскую книгу.

## Структура каталогов

```
docs/
├── en/
│   ├── SUMMARY.md
│   ├── index.md
│   └── guides/quickstart.md
├── zh-Hans/
│   └── ...
```

Каждый подкаталог `docs/` — это один язык. `SUMMARY.md` управляет боковой панелью.

## Поддержка Markdown

Заголовки, абзацы, код в ограждении, списки, цитаты, таблицы, тематические разделители,
изображения, а также строчный `код`, **жирный**, *курсив*, [ссылки](./architecture.md).

> Цитаты также поддерживаются.

## Изображения для светлой и тёмной темы

Скриншоты, которые должны отличаться на светлых и тёмных страницах, используют
принятое в экосистеме соглашение о фрагменте URL — `#gh-light-mode-only` /
`#gh-dark-mode-only` от GitHub или псевдонимы mkdocs-material `#only-light` /
`#only-dark`:

```markdown
![Панель в светлой теме](dashboard.webp#gh-light-mode-only)
![Панель в тёмной теме](dashboard.dark.webp#gh-dark-mode-only)
```

Фрагмент удаляется из итогового `src`, и страница скрывает вариант, не
соответствующий `prefers-color-scheme` читателя. Изображение без фрагмента
принадлежит обеим схемам, поэтому обычному скриншоту достаточно одного файла по
умолчанию (светлого). Тот же markdown корректно отображается на GitHub, который
понимает запись `gh-*`.
